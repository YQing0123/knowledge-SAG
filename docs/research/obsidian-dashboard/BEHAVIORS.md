# Obsidian Dashboard 复刻行为说明

## 研究边界

目标是本机 Obsidian 插件源码目录，而不是可访问的网页。因此本次逆向以 `src/views/DashboardView.ts`、`src/views/ProjectBoard.ts`、`src/data/taskLogic.ts` 和 `styles.css` 为事实来源，提取已发布的 DOM 结构、CSS 令牌和事件处理。未宣称完成运行时浏览器截图像素比对；后续可在安装该插件的 Obsidian 实例中补做截图回归。

## 首页行为

- 首页由可配置模块注册表驱动，核心卡片顺序为：快速捕捉、TODO、工作进度、本周待办 & 逾期、项目情况，另有笔记统计和倒计时。
- 卡片采用 CSS Grid，支持列/行跨度；编辑态支持长按进入、拖动排序、拖动调整尺寸和拖到回收区域删除卡片。
- TODO 复用任务扫描结果，逾期优先、再按优先级排序；点击圆形勾选直接切换状态，点击文字打开编辑，右键提供编辑、延后、删除等操作。
- 工作进度使用两个 SVG 环形图：今日完成率与全部任务完成率。今日分母包含当天已经完成的任务，并排除“今日不做”节点。
- 本周卡片拆分为逾期提醒和本周待办；逾期项有红色边界与“逾期 N 天”标记。
- 项目情况使用项目行 + 任务统计 + 阶段管道；点击项目行进入项目总览甘特图，右键提供编辑和查看甘特图。
- 主题通过根节点 `data-theme` 切换，深色使用 `#0F1014` 基底、蓝紫强调色、低对比细线；浅色使用近白背景、黑色主色和中性边框。

## 项目页行为

- 项目页默认甘特图，左侧为项目筛选栏，右侧为视图区域。
- 视图标签为甘特图、列表、日历、看板；切换时只渲染当前视图，降低初次加载成本。
- 甘特图支持日/周/月/季度缩放、状态过滤、父子任务折叠、拖动任务条改日期和拖动边缘调整起止日期。
- 列表支持列排序、状态筛选、拖动排序、勾选完成、编辑和删除。
- 日历支持拖动任务到日期格；看板支持跨列拖动直接更新状态。
- 项目阶段由可点击节点和连接线组成，当前节点突出显示，已完成节点使用成功色。

## SAG 映射原则

| 插件概念 | SAG 实现 |
| --- | --- |
| Vault 任务 Markdown | `ProjectTask` API 记录 |
| DashboardStore 刷新协调器 | `projectSnapshot` + 前端快照缓存失效 |
| 首页模块注册表 | `WorkbenchOverview` 卡片区块 |
| TaskEditModal / ProjectModal | SAG `Dialog` 编辑器 |
| ProjectBoard 多视图 | SAG Tabs + 列表/看板/日历/甘特组件 |
| frontmatter 阶段 | `ProjectStage` 与 `stage_index` |
