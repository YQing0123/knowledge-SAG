# 全部项目复刻组件规范

## 视觉规格

- 页面使用左侧项目导航 + 右侧主内容的双栏结构；侧栏宽约 220–240px，主区可横向滚动。
- 视图标签为紧凑 segmented tabs，激活项使用强调色和浅色底；默认激活甘特图。
- 甘特图左侧固定任务名称列，右侧时间轴；今日线、周末背景、任务条和父子层级必须清晰区分。
- 列表使用表头排序与状态点；看板按待办、进行中、阻塞、完成分列；日历按日期格展示任务。
- 阶段节点使用圆点与连接线，当前节点有 halo，点击节点触发乐观更新并在冲突时回滚提示。

## 交互验收

1. 进入“全部项目”默认打开甘特图，且只初始化当前视图数据。
2. 点击项目侧栏项后，任务数据只显示该项目；点击全部项目恢复全量。
3. 切换列表、日历、看板、甘特图不会丢失筛选条件和项目选择。
4. 拖动甘特任务条或日历任务到新日期，更新任务开始/截止日期；失败时显示错误提示并恢复原位置。
5. 看板跨列拖动更新状态；列表勾选、编辑、删除与 API 状态一致。
