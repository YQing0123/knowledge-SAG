# 总览复刻组件规范

## 视觉规格

- 页面背景使用低对比网格或中性背景，卡片使用 1px hairline 边框、4–10px 小圆角、无大面积渐变。
- 卡片标题左侧使用小型 marker/icon，右侧放统计摘要；标题字号 12–14px，正文以 12–13px 为主，数字使用等宽数字。
- 工作进度为两个独立 SVG 环形指标，分别展示“今日完成”和“总体完成”；圆环中心显示百分比，旁边显示完成数/总数。
- 任务列表使用紧凑行高，圆形状态控件在左、标题居中、优先级/逾期标签在右；完成项降灰并加删除线。
- 项目卡片展示项目颜色点、任务数、完成百分比和阶段连接线；当前阶段突出，已完成阶段使用成功色。

## 交互验收

1. 点击总览中的任务圆形控件，任务状态立即切换，两个进度环和项目统计同步更新。
2. 点击任务标题进入任务编辑弹窗；右键菜单至少提供编辑、删除和打开所属项目。
3. 点击“新建任务”打开弹窗，创建后任务进入当前快照，不刷新页面也能看到统计变化。
4. 点击项目阶段节点只更新该项目的 `stage_index`，并保留其它项目状态。
5. 空数据时显示可执行的空态，而不是空白卡片。
