# 个人工作台产品规划

## 1. 产品定位

个人工作台把「需求 → 项目 → 任务 → 执行 → 汇报 → 复盘」串成一个闭环。用户是唯一操作者，产品优先解决三件事：知道今天做什么、知道项目推进到哪里、能快速产出可复用的工作记录。

## 2. 一级模块

| 模块 | 解决的问题 | 一期入口 | 核心产物 |
| --- | --- | --- | --- |
| 总览 | 跨项目判断今天和本周的工作重点 | 工作台 / 总览 | 待办、完成率、逾期预警、项目进展 |
| 项目任务 | 把工作拆解并持续推进 | 工作台 / 全部项目 | 项目、阶段、任务、多视图 |
| 需求池 | 收集、澄清和评估还没有排期的想法 | 后续模块 | 需求、评估结论、验收标准 |
| 日报周报 | 将执行结果沉淀成汇报 | 后续模块 | 日报、周报、计划与复盘 |
| 数据报表 | 发现投入、完成、延期和需求转化趋势 | 后续模块 | 进度、效率、趋势报表 |

## 3. 模块关系

```text
需求池
  └─ 评估通过、关联项目
       └─ 转化为一个或多个任务
            └─ 任务状态、完成时间、延期记录
                 ├─ 总览：今日 / 本周 / 逾期 / 项目进度
                 ├─ 日报周报：自动汇总完成与计划
                 └─ 数据报表：按项目、周期、状态统计
```

关系规则：一个需求可以生成多个任务；任务必须属于一个项目；日报周报引用任务快照但允许补充文字；报表只读业务数据，不反向修改任务；删除使用软删除或取消，避免历史汇报失去来源。

## 4. 当前总览交互规范

- 顶部仅保留“总览 / 全部项目”两个工作台标签。
- “新建任务”使用弹窗，字段控制在项目、名称、截止日期、优先级四项，保存后关闭并刷新统计。
- “工作进度”展示今日完成 / 今日总任务、总完成 / 总任务，并用环图展示百分比；同时显示文字数字，不能只依赖颜色。
- “全部待办”排序：未完成优先，其次优先级高到低，再按任务开始时间倒序；完成任务保留在列表底部并使用删除线。
- 勾选按钮是独立操作目标：未完成任务变为完成，完成任务取消完成并回到待办区；请求期间按钮禁用并显示等待态。
- “本周已完成”按 `complete_time` 落在本周统计，支持取消勾选重新打开任务。
- “逾期预警”只显示截止日期早于今天且未完成的任务，并显示逾期天数和危险语义标签。
- 项目进展显示任务数、完成数、百分比、阶段条和当前节点；阶段项目与长期项目均可切换“立项 / 迭代 / 完结”。

## 5. 后续模块规格

### 需求池

状态：草稿、待分析、待评估、待排期、已纳入项目、已转任务、实施中、已完成、已拒绝、已搁置、已取消。

核心操作：新建、编辑、复制、评估、关联项目、补充验收标准、拆解任务、查看关联任务、搁置或拒绝并填写原因。

验收：需求可从草稿推进到评估；评估通过后能关联项目；单个需求可生成多个任务且每个任务保留来源需求；关联任务完成情况可回显到需求详情；拒绝和搁置必须有原因。

### 日报周报

日报自动汇总当日完成、进行中、新增、逾期任务和需求变化；用户补充“问题 / 风险 / 明日计划”。周报按周聚合完成量、延期量、项目变化、需求转任务和下周计划。

状态：草稿、已生成、已确认、已归档。确认后的报告保留生成时的任务快照，任务后续变化不覆盖历史报告。

验收：指定日期生成的日报只包含该日口径；修改任务后重新生成可得到最新草稿；确认后可导出 Markdown；报告中的任务可反向打开项目和任务详情。

### 数据报表

一期建议提供：任务完成率、按项目完成率、逾期趋势、状态分布、需求转任务率、周期内新增与完成量。

报表筛选：时间范围、项目、任务状态、优先级、需求来源。所有图表必须同时显示数字摘要或表格替代，支持空数据和加载失败状态。

验收：同一筛选条件下卡片、图表和明细数量一致；跨日期边界按用户时区计算；取消任务不计入完成率但保留历史明细；导出的数据与页面筛选结果一致。

## 6. 迭代顺序

1. 稳定总览和项目任务：完成状态、阶段切换、筛选排序、移动端可用性。
2. 需求池最小闭环：录入、评估、关联项目、转任务。
3. 日报周报：基于任务快照自动生成并支持 Markdown 导出。
4. 数据报表：先做只读统计，再增加导出和趋势对比。
5. 跨模块增强：需求验收标准、任务来源回溯、报告引用和报表下钻。

每期都要验证：数据口径、状态流转、异常恢复、键盘操作、深浅色对比、桌面宽屏布局。
